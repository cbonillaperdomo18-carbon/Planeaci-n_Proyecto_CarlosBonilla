# Planeación del Proyecto - Ferreeléctricos Bonilla Berlín Web

Este repositorio fue creado como parte de la **Actividad Desescolarizada (Sesión 2)** del programa **Análisis y Desarrollo de Software** del SENA.

## 🎯 Propósito del proyecto
El propósito del proyecto **Ferreeléctricos Bonilla Berlín Web** es automatizar los procesos de ventas, cotizaciones y atención al cliente de la ferretería **Ferreeléctricos Bonilla Berlín**, ubicada en Tesalia, Huila.  
A través de esta aplicación web se busca optimizar la gestión de productos, mejorar la experiencia de los clientes y facilitar la administración del negocio.

## 🧩 Fases planeadas del desarrollo
1. **Análisis de requisitos:** identificación de necesidades, usuarios y alcance.  
2. **Diseño:** elaboración de diagramas, arquitectura del sistema y prototipos.  
3. **Implementación:** desarrollo del frontend y backend usando tecnologías modernas.  
4. **Pruebas:** validación funcional y corrección de errores.  
5. **Despliegue:** publicación del sistema web y documentación final.

## 🧰 Tecnologías previstas
- **Frontend:** React.js  
- **Backend:** Node.js  
- **Base de datos:** MongoDB (NoSQL)  
- **Control de versiones:** Git y GitHub
